## Repository Structure

- `queue/` — Projects waiting to be completed.
- `src/` — Projects promoted by the daily GitHub Actions workflow.
- `.github/workflows/` — Automation for daily progression.

## Project Philosophy

Each project is designed to be hands-on. Projects progressively cover:

1. Terraform fundamentals and HCL
2. AWS infrastructure
3. Variables, expressions and data sources
4. Modules and reusable infrastructure
5. State, backends and imports
6. Multi-environment and multi-account patterns
7. Security and secrets
8. Terraform testing and validation
9. GitHub Actions CI/CD
10. Enterprise Terraform architecture

## Prerequisites

- Terraform CLI
- AWS account
- AWS CLI
- Git
- GitHub account

Configure AWS credentials before applying AWS projects.

> Never commit real credentials, secrets, `.tfstate` files, or private keys.

## Daily Automation

The scheduled workflow finds the lowest-numbered project in `queue/`, moves it into `src/`, updates this README, commits, and pushes the change.

After Day 100, the workflow removes the empty `queue/` directory.
